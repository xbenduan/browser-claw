# Browser Claw：自然语言驱动的可控 API 执行浏览器扩展

## 一句话定位
Browser Claw 是一款 Chrome MV3 扩展，目标是把“自然语言需求”转成“在当前网站上下文中可控执行的 API 调用”，以 Human-in-the-Loop 的方式在保证安全的前提下提升后台操作效率。

## 背景与问题
在电商后台、运营平台、CMS 等场景中，批量操作通常需要：
- 手动在页面上重复点击
- 或者编写脚本但需要处理鉴权、跨域与 Token 管理

这导致自动化成本高、风险大、难以复用。Browser Claw 的设计目标是在浏览器内完成“可控自动化”，既复用当前登录态，又把执行权留在用户手中。

## 核心思路
项目采用三条核心设计主线：

1. **Skill-as-Document**
   - 用结构化文档定义接口能力，而不是写死代码
   - 每个 Skill 描述：接口含义、参数 schema、风险等级、站点绑定
   - 新增能力更像“写文档”，降低扩展成本

2. **浏览器即运行时**
   - Content Script 在目标页面上下文中发起请求
   - 自动携带 Cookie/Session，规避跨域与鉴权障碍

3. **强制确认（Mandatory Confirmation）**
   - 每次真实 API 调用前必须向用户展示 URL/参数/风险
   - 用户确认后才执行，避免误操作与不可逆风险

## 系统架构概览
系统由三端协作构成：

- **Popup / Side Panel（UI）**：配置模型、管理 Skills、创建会话、执行对话
- **Background Service Worker**：消息中转、Side Panel 拉起、存储初始化
- **Content Script**：在页面上下文执行请求、读取页面信息、返回结果

通过统一的消息协议与存储层联动，实现从“自然语言指令”到“受控 API 调用”的闭环。

## 关键能力模块
项目中最能体现工程能力与产品判断的模块包括：

- **Skill 管理**
  - 可视化增删、批量导入导出、按站点匹配
  - Skill 定义与模型工具调用对齐

- **Agent 引擎**
  - 基于 OpenAI 兼容 SDK 的 tool calling
  - 结合系统提示词与站点 Skills 完成多步任务编排
  - 对大响应做存储与检索，降低 token 负担

- **请求代理层**
  - 在 Content Script 中执行 fetch
  - 支持超时/取消/CSRF 附加
  - 保证请求使用浏览器内会话态

## 典型工作流
以“批量更新商品售卖时间”为例：

1. 用户自然语言下达任务
2. LLM 选择对应 Skill 并生成参数
3. 展示确认卡，用户确认
4. Content Script 在页面内发请求并返回结果
5. LLM 根据结果继续规划下一步

这使复杂任务变成可视、可控、可回溯的流程。

## 安全与可控性
项目通过机制保证安全性：
- 所有真实 API 调用前必须确认
- 请求在浏览器沙盒执行，凭据不外流
- 高风险操作提示风险等级与影响范围

## 技术栈与工程形态
项目采用现代前端与扩展技术栈：
- Chrome Extension MV3 + React 19 + TypeScript 5.8
- Tailwind CSS 4 + Vite 7 + @crxjs/vite-plugin
- OpenAI 兼容 SDK 进行 tool calling

Browser Claw 的核心价值在于让“自然语言指令”真正落地为“可控的 API 自动化执行”，并通过扩展架构天然解决鉴权与跨域问题。这个项目同时体现了产品洞察、工程设计、安全策略与 AI 编排能力，适合作为面试中展示“构思到实现”的完整案例。
